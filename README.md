# Biblioteca Escolar

Sistema de consola desarrollado en C# y .NET para gestionar el registro de libros de una biblioteca escolar.

## Objetivo

Crear una aplicación que permita organizar la información de los libros y sentar las bases para incorporar funcionalidades de gestión en las siguientes etapas.

## Tecnologías

- C#
- .NET
- Git
- GitHub

## Estructura del proyecto

```text
BibliotecaEscolar/
├── src/
│   ├── BibliotecaEscolar.csproj
│   └── Program.cs
├── .gitignore
└── README.md
```

## Ejecución

Desde la raíz del repositorio:

```bash
dotnet run --project src/BibliotecaEscolar.csproj
```
